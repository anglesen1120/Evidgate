## 1. Goal and non-goals

**Goal.** One GitHub Actions pipeline that runs exactly what `scripts/verify.sh` runs locally — locked restore, build, analyzers, unit, integration (Testcontainers), architecture tests, contract drift, web build — plus the licence gate, branch protection and supply-chain hardening, in under 10 minutes. A PR with a compile error, a drifted contract, a denied-licence dependency or an unformatted file is blocked by required checks.

**Non-goals.** Deployment/release pipelines and image builds (10.2.1); publishing the CLI/adapters to a registry (04/10); CodeQL (11.6.1 owns it per T40 — this story keeps the runner hooks ready); Evidgate-ingests-Evidgate (01.10.1).

## 2. User stories and acceptance criteria

- As a developer, a PR that fails `scripts/verify.sh` locally fails CI with the same output, so CI surprises are impossible.
- As the Tech Lead, a new dependency with AGPL/SSPL/BUSL/RPL/non-commercial/paid-maintenance licence fails a required check and names the package, so the licence rule is enforced, not documented.
- As the Tech Lead, every GitHub Action is pinned by commit SHA and lock-file changes trigger dependency review, so supply-chain rules hold on our own repo.

| # | Acceptance criterion (testable) |
|---|---|
| AC1 | `.github/workflows/ci.yml` runs on PRs and pushes to `develop`/`main`: `dotnet restore --locked-mode`, `npm ci`, build, analyzers, `dotnet test` (unit + integration on runner Docker ✅, run [36205176754](https://github.com/anglesen1120/Evidgate/actions/runs/36205176754)), architecture tests, `npm run codegen` + `git diff --exit-code` drift gate, web build — all green on a trivial PR |
| AC2 | `scripts/verify.sh` and the workflow run the same commands in the same order (workflow calls `verify.sh` stages, not parallel copies) — a deliberate divergence fails a workflow-lint test |
| AC3 | Wall time of a warm-cache run < 10 min (NFR-01-1 target); cache keys for NuGet (`packages.lock.json` hash) and npm (`package-lock.json` hash) are hit on a no-dependency-change PR |
| AC4 | Adding `package.json` dependency with an AGPL licence (test branch) fails the licence gate naming the package; adding one missing from ADR-0002 fails `check-adr-matrix.sh` |
| AC5 | Branch protection on `main`/`develop` requires the verify + licence + isolation-suite checks and CODEOWNERS review; a PR bypassing checks cannot merge (verified by a throwaway PR) |
| AC6 | Every `uses:` in workflows pins a full-length commit SHA; `dependabot.yml` covers NuGet + npm + GitHub Actions; `dotnet list package --vulnerable --include-transitive` and `npm audit --omit=dev` gates exist with a documented exception file |
| AC7 | CycloneDX SBOMs for both ecosystems are produced per build and uploaded as artifacts ⚠️ tool licence confirmed in this task |

## 7. Jobs and integrations

- GitHub Actions runners must run Docker for Testcontainers — ✅ verified on `ubuntu-latest` via the interim `.github/workflows/docker-tests.yml` (88 tests green, [run 36205176754](https://github.com/anglesen1120/Evidgate/actions/runs/36205176754), area §11). `docker-tests.yml` is interim evidence only: it is **deleted, not extended**, when `ci.yml` lands — AC2 forbids a parallel copy. Pending fixes folded into T1: `global-json-file: global.json` SDK pin, single trigger (drop the duplicate `pull_request`/`push` double-run), `ubuntu-24.04` pin (`ubuntu-latest` migrates to Ubuntu 26 on 2026-10-19).
- Dependabot PRs flow through the same gates (a bumped dependency still needs ADR-0002 row via `check-adr-matrix.sh` — that is intentional, it makes upgrades evidence-driven, area §5).
- Produced artifacts (SBOM, test results, Playwright report on failure) are also the input format dogfooded by 01.10.1-T1 — keep them in standard formats (JUnit XML, CycloneDX JSON).
- 11.6.1 hooks CodeQL into this pipeline later; `ci.yml` reserves a `security` stage scaffolded but empty.

## 11. Rollout

- Checks become required the same PR they land (order: T1 first so required-check names exist, then T3 enables enforcement).
- Monitoring: workflow duration tracked in the run summary; licence-gate noise kept low by a small explicit deny list (area risk row).
- Rollback: disable required checks + remove workflow; local `verify.sh` unchanged.
