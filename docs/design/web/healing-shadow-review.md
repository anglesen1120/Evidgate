## Invariants

- **Shadow first; original untouched:** raw FAIL/attempt #1/`ev-3` is before the proposal and shadow blocks; green sandbox evidence never replaces it (page 13:76–88,204–215). [DECISIONS §5.3](../../../DECISIONS.md) forbids deleting/overwriting original evidence or replacing an official run.
- **Never apply from the UI; PR delivery only:** persistent proposal-only banner and repository-delivery footer explicitly prohibit Apply/direct commit/merge/runtime execution (page 13:55,231,248). V1 read-only routes contain no approval/rejection bindings (09.5.1 AC3); page 14 is a separate V2 capability, not permission to add such controls to page 13. Runtime auto-apply stays off in V1/V2 and G1–G3 (DECISIONS §5.7).
- **Never remove/weaken assertions:** one targeted locator change retains semantic role/name, unique match, business region, post-condition and assertion hash; equal hashes alone are insufficient; negative control must still fail (page 13:109–122,184–199). Preserve all forbidden-mechanics rules in DECISIONS §5.1–§5.4, including no skip/fixme, force-click, catch-and-ignore or mocking a business result.
- **Approval binds exact context:** hash/base/If-Match revision are visible, rebase requires revalidation (page 13:93–104,194,241); page 14's independent-review notice and full synthetic hash/base dialog are separate review evidence (page 14:71,95–108,202–215). Sensitive cases require a different reviewer under DECISIONS §5.5 and ruling T35.
- **Completeness, test outcome and release decision are not interchangeable:** original artifact metadata, validation outcomes, sandbox outcome, window completion and PR state are separate facts. No G3 release verdict is created by merging a PR (page 13:85–88,205–226,237). Missing validation is not PASS (193,198); `shadow-running` uses neutral pending badges and no result (205–207,239).
- **No invented safety confidence or artifacts:** sample count is explicitly not probability (190,211); structural diff unavailable is not equality (159). Screenshots require project opt-in plus ready/access-allowed artifact state; otherwise metadata only (163–171).
- **Fail closed for healing, not testing:** related queue dependency/disabled states keep tests and gates running (page 12:58–59); `unavailable` is derived, not an editable operator value (page 16:67,148–154), matching DECISIONS §5.9 and ruling T33.
