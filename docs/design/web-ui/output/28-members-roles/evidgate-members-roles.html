Design notes

Light brand tokens follow the Evidgate spec. The supplied muted shade is retained as a brand token; accessible muted copy and action-fill shades are derived for contrast. Dark colors, status colors, spacing and radii are proposed app tokens. Font files were not supplied; Manrope and Public Sans use system fallback stacks.
