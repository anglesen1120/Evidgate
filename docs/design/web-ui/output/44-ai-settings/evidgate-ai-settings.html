Writing style: Use short, observable steps with one action per line.

Coverage strategy: Cover happy path, validation, payment failure and retry for each checkout step.

Exclusion rules: Exclude destructive production actions and any step requiring real payment credentials.

Step detail: One action per step with an observable expected result and no hidden setup.
