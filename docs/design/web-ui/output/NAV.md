# Navigation map (S50 Web UI v2)

Paths are relative to `docs/design/web-ui/output/`. Every page links `assets/evidgate.css` and `assets/evidgate.js`; the sidebar is generated by `assets/evidgate.js` from its nav registry, so links and phase visibility are edited in one place. Open `index.html` for the full page list and `00-components/` for the component gallery.

Phase column: the CR-D-2 phase in which the page is shown (G1–G4). Pages marked G4 are hidden from navigation until the phase switch in the top bar is set to G4; they carry a "G4 reference" banner. Pages 17–19 also carry the B5-01 retired-Studio banner.
