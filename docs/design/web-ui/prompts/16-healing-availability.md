# Evidgate — Healing availability and scoped kill switches

## Shared design brief (inlined; no repository access required)
Evidgate is an evidence-first test collection and release-decision workspace for QA engineers, test maintainers, release approvers and tenant admins. Use a calm, precise operational interface, not a marketing dashboard. Display illustrative data explicitly. Server-declared, project-scoped permissions govern routes and actions; the server remains authoritative. Viewer is read-only; QA runs/triages; maintainers review tests/healing; release approvers own policies/waivers; admins manage access/integrations. Support operators require an audited scope and expiry.

Continue the landing brand: cool pale surfaces, navy text, restrained teal evidence-path/action accent, hairline separators, no decorative gradients or shadows. Light tokens: bg oklch(99% 0.002 240), surface oklch(100% 0 0), fg oklch(23% 0.035 250), muted oklch(54% 0.012 250), border oklch(92% 0.005 250), accent oklch(43% 0.075 195). Manrope display (tracking −0.038em), Public Sans body, SFMono-Regular/Consolas/Liberation Mono for hashes/code; Vietnamese glyph support required. Wordmark “Evidgate” with a small outlined shield/check is a brand mark, never a verdict. Dark theme and app-only spacing/type/radius/status tokens are design proposals, not previously approved brand tokens: define CSS variables, preserve hierarchy, measure contrast in both themes.

Dense, legible tables with explicit column headers, cursor pagination (50 default, 200 maximum), bounded overflow, full-value access for long hashes/names. Desktop ≥1280 primary (1440 canvas); tablet 768–1279 collapses navigation and stacks secondary panels; <768 is read-only fallback with a desktop-required notice, no mutation controls, no page overflow, and 44×44 touch targets. Use light + dark; vi + en switch, 30–40% Vietnamese expansion, UTC raw timestamps. WCAG 2.2 AA: text ≥4.5:1, large text/UI ≥3:1, semantic HTML, visible keyboard focus, skip link, labelled errors/live status, dialog focus trap/return and Escape, reduced motion.

Collection completeness, test outcome and release decision are THREE SEPARATE labelled fields. PASS green, FAIL red, INCONCLUSIVE amber must also use text/icons; pending is neutral gray and verdict-free. Render stored evaluations only: missing evidence never implies PASS, a confirmed assertion failure remains FAIL even with incomplete collection. Preserve original raw status, attempts and evidence revision beside any healing/shadow result; flaky and healed are separate labels. No release approval in healing views; no healing approval in release/policy views; no apply control in V1 or V2.

Never display secret values, passwords, session cookies, raw presigned URLs, credential-bearing snippets or request bodies. Only metadata/prefixes are allowed. Source plans' one-time-secret reveal is unresolved against this assignment: illustrate the lifecycle with a redacted field and copy feedback, never generate or reveal a credential. Render logs/diffs/AI text as untrusted plain text; artifact HTML belongs only on an isolated viewer origin.

## Interaction and state contract
Provide a clearly separated **design review state switcher** (not production navigation): default, loading, empty, error, 403 and 412, plus the page-specific scenarios below. Loading reserves final-layout space and disables duplicate submissions; empty differentiates no resources from no filter matches; errors retain safe context, request id and a deliberate retry. 403 is an in-scope permission error; foreign-tenant/unknown ids render indistinguishable 404 “Not found / Không tìm thấy”. 401 re-auth preserves the safe return route; 429 shows server Retry-After, not a guessed timer. Success is shown only after the supplied server result. Include hover, focus-visible, pressed, disabled, submitting, success and long-content variants.
412 means “Someone else changed this — reload / Người khác đã thay đổi dữ liệu — tải lại”: show current revision and changed fields/diff, retain the unsaved draft visibly, offer explicit Reload, never auto-merge or silently resubmit. On read-only pages, switcher 412 is the shared conflict-pattern demonstration from a linked editing action, explicitly NOT an invented read-endpoint response. Resource-creation retries reuse one Idempotency-Key per intent; cancel 202 means recorded, not completed. All dates/amounts/sample counts below are illustrative fixture values, never live claims.
